Gustaf Browser

Setup herunterladen und installieren

Setup herunterladen
Gustaf.Setup.1.0.0.exe · Windows

Anleitung

  1. Browser herunterladen Lade die Setup-Datei über den Button oben herunter.
  2. Installieren Starte die heruntergeladene Setup-Datei und folge der Installation.
  3. Access Key eingeben Öffne den Browser nach der Installation und gib beim ersten Start deinen Access Key ein, um die Anwendung zu aktivieren.
  4. Konfigurationsdatei einrichten (nur beim ersten Mal) Wähle im Dropdown-Menü das Python-Skript aus und ziehe deine Konfigurationsdatei hinein (oder lade sie hoch). Installiere anschließend die angezeigten Abhängigkeiten. Danach die Datei noch einmal hineinziehen — alles Weitere öffnet sich automatisch.
  5. Prüfungsmodus Über den Button unten links lassen sich ablenkende Informationen ausblenden, sodass nur noch die Zeit und die wichtigsten Angaben sichtbar bleiben.
